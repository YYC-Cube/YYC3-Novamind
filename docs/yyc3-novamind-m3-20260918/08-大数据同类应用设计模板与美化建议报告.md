### 1.2 根因归纳

- **无单一设计令牌来源**：颜色/间距/圆角散落在各页面硬编码（`#8B5CF6`、`rounded-3xl`、`shadow-purple-500/25` 等 magic value 遍布）
- **页面各自为政**：无页面级模板抽象，同类页面（4 个生成器页、4 个结果页）各自实现相似布局
- **随机性/时间性数据未隔离**：SSR 渲染路径混入 `Math.random()`/`new Date()`

## 二、行业调研成果

### 2.1 同类应用首页设计方案（2026）

| 方案 | 代表 | 核心优势 | 视觉特点 | UX 亮点 |
| ---- | ---- | -------- | -------- | ------- |
| **对话画布混合** Conversational-canvas | AI 产品主流趋势 | 对话与产物创作并排，降切换成本 | 暗色画布 + 对话流左、产物右 | 多模态输入区（本项目已具备雏形） |
| **Agent 动作流** Agent action streams | Agentic 工作流产品 | 多步任务可视化，建立信任 | 步骤时间线 + 实时状态徽章 | 内联审批 + 撤销状态 |
| **摘要卡片 > 图表墙** | 数据重 AI 仪表盘 | 认知减负，先结论后细节 | 指标卡（点 + 百分比 + vs 30d + 迷你 sparkline） | 数字滚动动画仅在值变化时触发 |
| **沉浸 Hero + 上下文 mockup** | AI SaaS Landing | 首屏即传达产品力 | 高对比视觉 + 首屏内嵌暗色仪表盘截图 | CTA 明确（Book a demo / Discover） |
| **克制的信任感设计** | 企业级分析平台 | 层级靠字重不靠装饰 | 1px 边框无阴影、限量配色 | 「动效即语义」：idle 仪表盘保持安静 |

**共同趋势提炼**：
1. 暗色模式为 AI 产品默认审美（本项目 ✅ 已符合）
2. Token 化设计系统 + 明暗即时切换成为标配
3. 玻璃拟态（glassmorphism）仍主流但克制使用（本项目首页 backdrop-blur 已在用）
4. AI 生成内容的展示模板化：thinking 状态、流式输出、成功/错误微动效成套

### 2.2 翻页动画与全局 UI/UX 模式

| 模式 | 实现 | 适用场景 | 关键参数 |
| ---- | ---- | -------- | -------- |
| **View Transitions API**（2026 主流） | 浏览器原生，React `<ViewTransition>` key 驱动 | 列表 → 详情方向性滑动 | `share="auto"` 共享元素交叉淡入 |
| **Framer Motion 布局动画** | `motion` 组件（34KB）或 LazyMotion 减包 | 复杂编排、共享元素 | 需权衡 bundle 成本 |
| **Apple 节奏交叉淡入** | 预设 transition | 通用页面切换 | **~200ms**，强化「轻快」感 |
| **上下文局部淡入** | `view-transition-name` 只标注 `<main>` | 导航/侧栏稳定的内容区切换 | 避免整页动画的眩晕感 |
| **方向性滑动** | 水平位移 + 层级映射 | 有明确层级关系的导航（列表→详情） | 强化用户心智模型 |

**选型建议（本项目）**：Next.js App Router 下优先 **View Transitions API**（零 JS 包体积），Next 15.2+ 已有实验性 `<ViewTransition>` 支持；Framer Motion 仅用于首页粒子/手势等高频微交互。

### 2.3 设计系统模板化行业范式

- **Token 单一来源**：色彩/字号/间距/圆角一份定义，人和 AI agent 共读（ai2.design: 51 个 shadcn 兼容组件全变体矩阵 + MCP-ready 文档）
- **页面级模板**：44+ 全屏模板（onboarding/chat/dashboard/settings 流）开箱即用
- **动效组件化**：22 个预置动效（loader/thinking/success/error）随系统分发
- **DESIGN.md 即代码**：设计规范存仓库，随代码演进（OpenDesign 152 个开源设计系统实践）

### 6.2 P1 起步代码骨架（建议）

```css
/* app/tokens.css — 单一令牌来源（P1 交付物） */
:root {
  --brand-primary: #8b5cf6;      /* NovaMind 紫 */
  --brand-gradient: linear-gradient(90deg, #60a5fa, #c084fc, #f472b6);
  --surface-card: 1px solid rgb(255 255 255 / 0.1);
  --radius-card: 1.5rem;
  --motion-page: 200ms cubic-bezier(0.4, 0, 0.2, 1); /* Apple 节奏 */
}
.dark { --surface-card: 1px solid rgb(255 255 255 / 0.15); }
```

```tsx
// app/template.tsx — 全局翻页动画（P3 交付物，零依赖）
"use client"
export default function Template({ children }: { children: React.ReactNode }) {
  return <div style={{ animation: "pageIn var(--motion-page)" }}>{children}</div>
}
```
