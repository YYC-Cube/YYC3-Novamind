# 🔐 生产供给配置手册

> **原则**：本手册所有密钥均为**占位符**，真实值仅在本地 `.env.local` / 部署平台环境变量中填写。
> 文档中一律使用 `${ENV_VAR}` 或 `<占位符>` 格式，**严禁记录真实密钥**。

| `OPENAI_API_KEY` | ⏳ | **待用户注入真实 Key**；缺失时 AI 生成/RAG embedding/摘要模型全链路自动降级（已验证不崩溃） |

**权限修正**：迁移产物 owner 为本地用户，需 `GRANT SELECT,INSERT,UPDATE,DELETE ON ALL TABLES` 给应用角色。

## 一、会话密钥生成（AUTH_SECRET）

```bash
# Auth.js v5 会话加密密钥 —— 本地执行后复制输出值填入 AUTH_SECRET
openssl rand -base64 32
# 输出示例（占位符格式）：<base64-44-chars-random-string>
```

| 配置项 | 填写位置 | 值格式 | 备注 |
| ------ | -------- | ------ | ---- |
| `AUTH_SECRET` | `.env.local` / 部署平台 Env | `openssl rand -base64 32` 输出 | 缺失时 build 不报错，运行时受保护路由要求配置（[auth.config.ts](../../../auth.config.ts)） |
| `AUTH_ADMIN_EMAILS` | 同上 | 逗号分隔邮箱 | 命中白名单 → admin 角色；缺省全为 user |

## 二、数据库配置（DATABASE_URL）

```bash
# DSN 占位符模板 —— 五个尖括号字段按实际替换
export DATABASE_URL="postgresql://<DB_USER>:<DB_PASSWORD>@<DB_HOST>:<DB_PORT>/<DB_NAME>?sslmode=require"

# ── 迁移执行（DSN 就绪后）──────────────────────────
pnpm db:migrate                          # Drizzle 四表：users/chats/messages/feedback
psql "$DATABASE_URL" -f drizzle/0000-rag-pgvector.sql   # RAG 向量表：documents/chunks + HNSW/GIN 双索引
```

| 字段 | 说明 | 常见取值 |
| ---- | ---- | -------- |
| `<DB_USER>` / `<DB_PASSWORD>` | 数据库凭据 | 由 DBA 或托管平台发放 |
| `<DB_HOST>` | 主机地址 | Neon/Supabase/自建 PG 均可 |
| `?sslmode=require` | 加密传输 | 托管平台必带；本地开发可省略 |

**DSN 驱动降级**（[lib/db/index.ts](../../../lib/db/index.ts)）：`DATABASE_URL` 缺失 → `isDbEnabled=false`，持久化静默跳过，应用以内存态正常运行——因此本项可 P2 最后拟定，不阻塞开发。

## 三、AI 服务密钥

```bash
# OpenAI 兼容密钥（资产 4/5/6 依赖；缺失时 ai-tools/RAG 自动降级）
OPENAI_API_KEY=<sk-your-key-here>
OPENAI_BASE_URL=<https://your-proxy.example.com/v1>   # 可选：代理/私有网关
OPENAI_MODEL=gpt-4o                                    # Agent 循环默认模型
```

## 四、一键校验脚本（可选）

```bash
#!/usr/bin/env bash
# scripts/verify-env.sh —— 逐项检查生产供给四要素
check() { [ -n "${!1}" ] && echo "✅ $1 已配置" || echo "❌ $1 缺失"; }
check AUTH_SECRET
check DATABASE_URL
check OPENAI_API_KEY
check AUTH_ADMIN_EMAILS
```

## 五、安全红线（团队规范摘要）

- [ ] `.env*` 已在 `.gitignore`，严禁提交真实密钥
- [ ] 文档/日志/截图中密钥一律 `${VAR}` 或 `[REDACTED]` 占位
- [ ] 生产密钥仅存部署平台（Vercel Env / GitHub Secrets），本地不入库
- [ ] 密钥轮换：AUTH_SECRET 轮换会使全部会话失效，需公告后执行
