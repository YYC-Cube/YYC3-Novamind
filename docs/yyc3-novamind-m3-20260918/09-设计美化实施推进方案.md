## 三、P1 建基：Design Token 单源 + 暗色贯通

### Task P1-1: 建立 Token 单一来源

- **涉及**：新建 `app/tokens.css`；`app/globals.css` 引入
- **动作**：
  1. 定义品牌令牌：`--brand-primary: #8b5cf6`、`--brand-gradient`、`--surface-card`、`--radius-card`、`--motion-page`
  2. `:root`（浅色）/ `.dark`（深色）双套值；补充间距令牌 `--space-1~8`（4px 基准）
- **验收**：`pnpm typecheck` 0E；两个页面接入后视觉无回归

### Task P1-2: Tailwind 桥接

- **涉及**：`tailwind.config.ts`（或 CSS-first `@theme`）
- **动作**：把 CSS 变量映射为 Tailwind 语义色（`bg-surface`、`text-brand`、`rounded-card`），新旧类名共存渐进替换
- **验收**：构建通过；现有页面零破坏（新旧类等价渲染）

### Task P1-3: 示范改造 3 页

- **涉及**：`app/page.tsx`、`app/history/page.tsx`、`app/settings/page.tsx`（magic value → 语义令牌）
- **动作**：替换 `#8B5CF6`/`rounded-3xl`/`shadow-purple-500/25` 等 hardcode 为 `var(--*)`/语义类
- **验收**：grep 确认 3 页内无品牌色 hex 直写；暗色切换前后截图对比无破损

### Task P1-4: 全站暗色审计

- **涉及**：`app/**/page.tsx` 中 `bg-white`/`bg-gray-50` 等浅色硬编码（重点：mindmap-result、favorites、learning）
- **动作**：逐一替换为令牌化表面色；`next-themes` 已有，验证 ThemeProvider 全局生效
- **验收**：暗色模式遍历 12+ 主页面无明显白块/不可读文本

**里程碑 M-P1**：Token 单源落地 + 暗色全站贯通 + 3 页示范

## 四、P2 模板化：页面壳沉淀

### Task P2-1: GeneratorPageShell（生成器页模板）

- **涉及**：新建 `components/templates/generator-page-shell.tsx`；接入 `app/generate/{mindmap,poster,ppt,webpage}/page.tsx`
- **抽取共性**：生成中进度态 / 手势提示区 / 返回导航 / 底部操作栏
- **验收**：4 页接入后各保留差异 props（标题/进度文案/动作区 children）；单测覆盖 Shell 渲染

### Task P2-2: ResultPageShell（结果页模板）

- **涉及**：新建 `components/templates/result-page-shell.tsx`；接入 `app/{mindmap-result,ppt-result,poster-result}/page.tsx`
- **抽取共性**：loading 骨架 / 404 态 / 顶部工具栏（缩放/导出/分享）/ 底部信息栏
- **验收**：3 页接入；各结果页差异区（SVG/幻灯片/海报）通过 children 注入

### Task P2-3: 摘要卡片组件（行业范式对标）

- **涉及**：新建 `components/summary-card.tsx`（点 + 值 + vs 基线 + sparkline）
- **动作**：先用于 `app/admin/usage/page.tsx` 聚合展示；数字滚动仅在值变化时触发（动效即语义）
- **验收**：admin/usage 看板渲染正常；组件 props 文档注释完整

**里程碑 M-P2**：2 壳组件 + 7 页接入 + 摘要卡片上线

## 五、P3 动效 + P4 智能化

### Task P3-1: 全局翻页动画

- **涉及**：新建 `app/template.tsx`（零依赖 CSS animation `pageIn`，200ms Apple 节奏）
- **验收**：页面切换有轻快淡入；`prefers-reduced-motion` 下自动禁用

### Task P3-2: View Transitions 列表→详情

- **涉及**：`app/conversations/page.tsx` → `conversation/[id]`、`app/learning/page.tsx` → `learning-path/[id]`
- **动作**：`document.startViewTransition` 特性检测封装 `navigateWithTransition()`；不支持的浏览器优雅降级
- **验收**：Chrome 111+ 可见共享元素过渡；Safari/Firefox 无报错直跳

### Task P4-1: AI 一句话换肤

- **涉及**：`app/api/ai/route.ts` 新 action `generateTheme`；新建 `lib/theme-schema.ts`（JSON schema 校验）；`app/settings/page.tsx` 换肤入口
- **动作**：LLM 结构化输出 Token 主题包（色彩 6 值 + 圆角 + 字重）→ 预览 → 应用到 `:root`（经 usage 计量，D9 旁挂自动记录）
- **降级**：无 OPENAI_API_KEY 时按钮隐藏（D10 同款降级模式）
- **验收**：输入「海洋风格」生成合法主题包并实时预览；usage_logs 落库可查

**里程碑 M-P3/P4**：翻页动效全局化 + View Transitions 双路径 + AI 换肤闭环
