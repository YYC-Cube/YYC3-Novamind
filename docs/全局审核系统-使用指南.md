## 🎮 使用方法

### 开始第一次审核

1. **访问主页**: 打开 <http://localhost:3004>
2. **点击审核入口**: 在主页找到"全局多维度审核系统"卡片并点击
3. **启动审核**: 点击"开始全面审核"按钮
4. **查看结果**: 系统将自动分析并生成详细报告

### 查看分析结果

审核完成后，您将看到：

- 📊 **总体评分**: 0-100分制综合评价
- 🏆 **质量等级**: A+到F的等级评定
- 📋 **维度详情**: 每个维度的具体得分和分析
- ⚠️ **问题清单**: 按严重程度排序的问题列表
- 💡 **优化建议**: 具体的改进方案和行动项
- 📈 **趋势图表**: 历史审核对比分析

### 评估标准配置

系统采用行业标准的评估准则：
